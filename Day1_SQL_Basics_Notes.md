#  Day 1: Database & SQL Fundamentals

## 1. What is a Database?
- A **Database** is an organized collection of structured information, or data, typically stored electronically in a computer system.
- **Real-life Example:** A phone contact list or a school student register.
- **Purpose:** To store, retrieve, and manage data efficiently.

## 2. What is DBMS?
- **DBMS (Database Management System)** is the software used to interact with the database. It acts as an interface between the user and the database.
- **Functions:** It allows users to Create, Read, Update, and Delete (CRUD) data.
- **Examples:** MySQL, Oracle Database, PostgreSQL, Microsoft SQL Server.

## 3. Types of Databases
Databases are broadly classified into two main types:

### A. Relational Databases (RDBMS)
- Data is stored in **Tables** (Rows and Columns).
- Tables are linked to each other using common fields (Keys).
- Uses **SQL** (Structured Query Language) to interact.
- **Best for:** Structured data, financial systems, e-commerce.
- **Examples:** MySQL, PostgreSQL.

### B. Non-Relational Databases (NoSQL)
- Data is NOT stored in tables. It is stored in documents (JSON), key-value pairs, or graphs.
- Highly flexible and scalable for unstructured data.
- **Best for:** Real-time apps, social media feeds, big data.
- **Examples:** MongoDB, Cassandra.

## 4. What is SQL?
- **SQL** stands for **Structured Query Language**.
- It is the standard programming language used to communicate with Relational Databases (RDBMS).
- **What it does:** 
  - Retrieve data (`SELECT`)
  - Insert records (`INSERT`)
  - Update records (`UPDATE`)
  - Delete records (`DELETE`)
  - Create databases and tables (`CREATE`)
